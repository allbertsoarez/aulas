# 💻 Códigos Fonte em C

Esta pasta armazena os arquivos de código-fonte em linguagem C (`.c`) relacionados à apostila de Linguagem de Programação. O objetivo é manter os exemplos práticos compiláveis e separados da teoria.

Os arquivos podem ser compilados em qualquer terminal usando o GCC (`gcc arquivo.c -o programa`) ou abertos em IDEs como Code::Blocks, VS Code ou Dev-C++.

## 📂 Índice de Arquivos

| Arquivo | Descrição | Tópico Relacionado |
| :--- | :--- | :--- |
| [`ola_mundo.c`](./ola_mundo.c) | Estrutura básica de um programa C, `#include` e `printf`. | 1. Introdução e 2. Estrutura Básica |
| [`variaveis_tipos.c`](./variaveis_tipos.c) | Declaração de variáveis (`int`, `float`, `char`, `double`) e formatação de saída. | 3. Variáveis e Tipos de Dados |
| [`entrada_saida.c`](./entrada_saida.c) | Uso do `scanf()` para leitura de dados do teclado e `printf()`. | 5. Entrada e Saída de Dados |
| [`condicionais_if.c`](./condicionais_if.c) | Estruturas de decisão `if`, `else if` e `else`. | 6. Estruturas de Controle |
| [`repeticao_for.c`](./repeticao_for.c) | Laços de repetição utilizando o `for`. | 7. Estruturas de Repetição |
| [`funcoes.c`](./funcoes.c) | Criação de funções com e sem retorno (`void`). | 8. Funções |

> **💡 Dica de Compilação:** 
> No terminal, navegue até esta pasta e use o comando:
> `gcc nome_do_arquivo.c -o nome_do_executavel`
> Para executar (no Linux/Mac): `./nome_do_executavel`
> Para executar (no Windows): `nome_do_executavel.exe`
