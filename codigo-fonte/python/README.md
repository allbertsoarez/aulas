# 🐍 Códigos Fonte em Python

Esta pasta armazena os arquivos de código-fonte em linguagem Python (`.py`) relacionados à apostila de Python. O objetivo é manter os exemplos práticos executáveis e separados da teoria.

Os arquivos podem ser executados em qualquer terminal com Python instalado (`python arquivo.py`) ou abertos em IDEs como VS Code, PyCharm ou Jupyter Notebooks.

## 📂 Índice de Arquivos

| Arquivo | Descrição | Tópico Relacionado |
| :--- | :--- | :--- |
| [`ola_mundo.py`](./ola_mundo.py) | Estrutura básica, comentários e a função `print()`. | 1. Introdução |
| [`variaveis_tipos.py`](./variaveis_tipos.py) | Tipagem dinâmica, `f-strings` e a função `type()`. | 2. Variáveis e Tipos de Dados |
| [`entrada_saida.py`](./entrada_saida.py) | Uso do `input()` para leitura e conversão de tipos (`int()`, `float()`). | 3. Entrada e Saída de Dados |
| [`condicionais_if.py`](./condicionais_if.py) | Estruturas de decisão `if`, `elif` e `else`. | 4. Estruturas de Controle |
| [`repeticao_for.py`](./repeticao_for.py) | Laços de repetição utilizando `for` e a função `range()`. | 5. Estruturas de Repetição |
| [`funcoes.py`](./funcoes.py) | Criação de funções com `def`, parâmetros e retorno. | 6. Funções |
| [`listas_dicionarios.py`](./listas_dicionarios.py) | Manipulação de Listas (arrays) e Dicionários (chave-valor). | 7. Estruturas de Dados |

> **💡 Dica de Execução:** 
> No terminal, navegue até esta pasta e use o comando:
> `python nome_do_arquivo.py`
> *(Se tiver Python 2 e 3 instalados, use `python3 nome_do_arquivo.py`)*
