# 💻 Códigos Fonte em C++ (Orientação a Objetos)

Esta pasta armazena os arquivos de código-fonte em C++ (`.cpp`) relacionados à apostila de Linguagem Orientada a Objetos. O objetivo é manter os exemplos práticos compiláveis e separados da teoria.

Os arquivos podem ser compilados em qualquer terminal usando o G++ (`g++ arquivo.cpp -o programa`) ou abertos em IDEs como VS Code, Code::Blocks ou CLion.

## 📂 Índice de Arquivos

| Arquivo | Descrição | Tópico Relacionado |
| :--- | :--- | :--- |
| [`ola_mundo.cpp`](./ola_mundo.cpp) | Estrutura básica, `#include <iostream>` e `cout`. | 1. Introdução |
| [`classe_objeto.cpp`](./classe_objeto.cpp) | Definição de uma classe (`class`) e criação de objetos (instâncias). | 2. Classes e Objetos |
| [`encapsulamento.cpp`](./encapsulamento.cpp) | Uso de `private`, `public`, métodos e getters para proteger dados. | 3. Encapsulamento |
| [`heranca.cpp`](./heranca.cpp) | Criação de Superclasse e Subclasse, reutilização de código. | 4. Herança |
| [`polimorfismo.cpp`](./polimorfismo.cpp) | Funções virtuais, classes abstratas e `override`. | 5. Polimorfismo |
| [`construtor_destrutor.cpp`](./construtor_destrutor.cpp) | Ciclo de vida do objeto, alocação e liberação de memória. | 6. Construtores e Destrutores |

> **💡 Dica de Compilação:** 
> No terminal, navegue até esta pasta e use o comando:
> `g++ nome_do_arquivo.cpp -o nome_do_executavel`
> Para executar (no Linux/Mac): `./nome_do_executavel`
> Para executar (no Windows): `nome_do_executavel.exe`
