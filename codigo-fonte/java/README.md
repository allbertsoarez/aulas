# ☕ Códigos Fonte em Java

Esta pasta armazena os arquivos de código-fonte em Java (`.java`) relacionados à apostila complementar de Linguagem Java. O objetivo é manter os exemplos práticos compiláveis e separados da teoria.

Os arquivos podem ser compilados em qualquer terminal com o JDK instalado (`javac Arquivo.java`) ou abertos em IDEs como IntelliJ IDEA, Eclipse ou VS Code.

## 📂 Índice de Arquivos

| Arquivo | Descrição | Tópico Relacionado |
| :--- | :--- | :--- |
| [`OlaMundo.java`](./OlaMundo.java) | Estrutura básica, `main` e `System.out.println`. | 1. Introdução |
| [`ClasseObjeto.java`](./ClasseObjeto.java) | Definição de classe e instanciação com `new`. | 2. Classes e Objetos |
| [`Encapsulamento.java`](./Encapsulamento.java) | Uso de `private`, `public` e `this`. | 3. Encapsulamento |
| [`Heranca.java`](./Heranca.java) | Herança simples usando a palavra-chave `extends`. | 4. Herança |
| [`Polimorfismo.java`](./Polimorfismo.java) | Classes abstratas, `@Override` e arrays polimórficos. | 5. Polimorfismo |
| [`Interfaces.java`](./Interfaces.java) | Criação e implementação de Interfaces (múltipla herança de tipo). | 6. Interfaces |

> **💡 Dica de Compilação e Execução:**
> No terminal, navegue até esta pasta e use os comandos:
> 1. Compilar: `javac NomeDoArquivo.java` (gera o arquivo `.class`)
> 2. Executar: `java NomeDaClasse` (sem o `.class` no final!)
