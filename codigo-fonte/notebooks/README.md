# 📓 Notebooks Jupyter - Ciência de Dados e Estatística Aplicada

Esta pasta armazena Notebooks Jupyter (`.ipynb`) que integram teoria estatística, manipulação de dados e visualização. O objetivo é demonstrar na prática como a programação (Python) resolve as limitações das planilhas tradicionais, conforme discutido na apostila de Estatística Aplicada.

Os notebooks podem ser executados localmente (Jupyter Notebook, VS Code) ou diretamente no navegador via **Google Colab** (basta fazer o upload do arquivo).

## 📂 Índice de Arquivos

| Arquivo | Descrição | Disciplinas Conectadas |
| :--- | :--- | :--- |
| [`01_pandas_editora.ipynb`](./01_pandas_editora.ipynb) | Introdução ao Pandas: criação de DataFrames, filtragem e manipulação de dados usando o cenário da Editora. | Banco de Dados + Python |
| [`02_estatistica_descritiva.ipynb`](./02_estatistica_descritiva.ipynb) | Cálculo de média, mediana, desvio padrão e geração de histogramas para análise de preços de livros. | Estatística + Python |
| [`03_correlacao_regressao.ipynb`](./03_correlacao_regressao.ipynb) | Análise de correlação entre ano de publicação e preço, com gráfico de dispersão e linha de tendência. | Estatística + Python |

> **💡 Dica de Execução:**
> 1. **Google Colab (Recomendado para iniciantes):** Acesse [colab.research.google.com](https://colab.research.google.com/), clique em "Upload" e envie o arquivo `.ipynb`.
> 2. **VS Code:** Instale a extensão "Jupyter" e abra o arquivo diretamente.
> 3. **Jupyter Notebook:** No terminal, navegue até esta pasta e execute `jupyter notebook`.
