# 📓 Notebooks Jupyter - Ciência de Dados e Python

Esta pasta armazena Notebooks Jupyter (`.ipynb`) para execução de códigos Python. O foco é a integração entre teoria estatística, manipulação de dados e a sintaxe básica da linguagem.

Os notebooks podem ser executados localmente ou diretamente no navegador via **Google Colab** (recomendado para laboratórios de informática).

## 📂 Índice de Arquivos

### 🐍 Módulo 1: Python Básico (Sintaxe e Fundamentos)
*Introdução à linguagem para quem está começando do zero.*

| Arquivo | Descrição |
| :--- | :--- |
| [`01_ola_mundo.ipynb`](./python-basico/01_ola_mundo.ipynb) | Introdução ao Colab, `print()` e primeiros passos. |
| [`02_variaveis_tipos.ipynb`](./python-basico/02_variaveis_tipos.ipynb) | Tipos de dados (`int`, `float`, `str`, `bool`) e tipagem dinâmica. |
| [`03_entrada_saida.ipynb`](./python-basico/03_entrada_saida.ipynb) | Leitura de dados (`input`), conversão de tipos e `f-strings`. |
| [`04_condicionais.ipynb`](./python-basico/04_condicionais.ipynb) | Estruturas de decisão: `if`, `elif`, `else`. |
| [`05_repeticao.ipynb`](./python-basico/05_repeticao.ipynb) | Laços de repetição: `for`, `range()` e `while`. |
| [`06_funcoes.ipynb`](./python-basico/06_funcoes.ipynb) | Criação de funções com `def`, parâmetros e `return`. |
| [`07_listas_dicionarios.ipynb`](./python-basico/07_listas_dicionarios.ipynb) | Estruturas de dados: Listas (arrays) e Dicionários (chave-valor). |

### 📊 Módulo 2: Estatística Aplicada e Ciência de Dados
*Integração de Python com Estatística e Banco de Dados (Cenário da Editora).*

| Arquivo | Descrição | Disciplinas Conectadas |
| :--- | :--- | :--- |
| [`01_pandas_editora.ipynb`](./01_pandas_editora.ipynb) | Introdução ao Pandas: criação de DataFrames e filtragem. | Banco de Dados + Python |
| [`02_estatistica_descritiva.ipynb`](./02_estatistica_descritiva.ipynb) | Média, mediana, desvio padrão e histogramas. | Estatística + Python |
| [`03_correlacao_regressao.ipynb`](./03_correlacao_regressao.ipynb) | Correlação, regressão linear e gráficos de dispersão. | Estatística + Python |

> **💡 Dica de Execução no Google Colab:**
> 1. Acesse [colab.research.google.com](https://colab.research.google.com/).
> 2. Vá em **Arquivo > Fazer upload do notebook** (ou abra direto pelo GitHub clicando no botão "Open in Colab").
> 3. O Colab é a solução ideal para laboratórios onde os PCs sofrem alterações constantes, pois todo o ambiente é executado na nuvem!
