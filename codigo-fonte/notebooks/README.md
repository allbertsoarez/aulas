# 📓 Notebooks Jupyter - Ciência de Dados e Python

Esta pasta armazena Notebooks Jupyter (`.ipynb`) para execução de códigos Python. O foco é a integração entre teoria estatística, manipulação de dados e a sintaxe da linguagem.

Os notebooks podem ser executados localmente ou diretamente no navegador via **Google Colab** (recomendado para laboratórios de informática).
