# 🧠 Biblioteca de Prompts Mestres

Esta pasta contém **templates e prompts mestres** prontos para uso em modelos de linguagem (ChatGPT, Claude, Gemini, Copilot, etc.). 

Assim como reutilizamos funções e classes na programação, podemos reutilizar **prompts estruturados** para obter resultados consistentes, profissionais e de alta qualidade da IA.

## 📂 Índice de Prompts

| Arquivo | Objetivo | Quando Usar |
| :--- | :--- | :--- |
| [`01_refatoracao_codigo.md`](./01_refatoracao_codigo.md) | Analisar, explicar e melhorar códigos existentes. | Quando o código funciona, mas está bagunçado ou sem comentários. |
| [`02_geracao_testes.md`](./02_geracao_testes.md) | Criar testes unitários e casos de borda para funções. | Antes de entregar um projeto ou para aprender a testar seu código. |
| [`03_resumo_estudos.md`](./03_resumo_estudos.md) | Resumir textos longos, apostilas ou documentações. | Para revisar matérias ou entender rapidamente um conceito novo. |
| [`04_template_agente.md`](./04_template_agente.md) | Estrutura base para criar um "Agente de IA" especializado. | Quando você precisa que a IA atue como um especialista com regras rígidas. |
| [`05_analise_dados.md`](./05_analise_dados.md) | Instruir a IA a analisar um CSV ou conjunto de dados. | Para gerar insights estatísticos rápidos a partir de dados brutos. |

## 💡 Como usar estes prompts?
1. Abra o arquivo `.md` desejado.
2. Copie o texto do prompt.
3. Cole na sua IA de preferência.
4. **Substitua os campos entre colchetes** (ex: `[INSIRA SEU CÓDIGO AQUI]`) pelos seus dados reais.
5. Ajuste o tom ou as restrições conforme sua necessidade.

> ⚠️ **Lembrete de Ética:** A IA é uma ferramenta de **aumento de produtividade**, não de substituição do pensamento crítico. Sempre revise, teste e entenda o que a IA gerou antes de usar em produção.
