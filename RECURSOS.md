# 🛠️ 2. Ferramentas Essenciais (Gratuitas)

Não tente aprender a programar sem as ferramentas certas. Estas são as mais usadas no mercado:

### 💻 Editores de Código (IDEs)
- [**VS Code**](https://code.visualstudio.com/): O editor mais popular do mundo. Leve, extensível e suporta todas as linguagens.
- [**IntelliJ IDEA Community**](https://www.jetbrains.com/pt-br/idea/): A melhor IDE para Java e Kotlin.
- [**PyCharm Community**](https://www.jetbrains.com/pt-br/pycharm/): Excelente para desenvolvimento Python.
- [**Code::Blocks**](http://www.codeblocks.org/) ou [**Dev-C++**](https://sourceforge.net/projects/orwelldevcpp/): Opções leves e clássicas para C e C++.

### 🗄️ Banco de Dados
- [**DBeaver**](https://dbeaver.io/): O "canivete suíço" dos bancos de dados. Conecta com MySQL, PostgreSQL, SQLite, etc.
- [**pgAdmin 4**](https://www.pgadmin.org/): Ferramenta oficial e mais completa para PostgreSQL.
- [**DB Browser for SQLite**](https://sqlitebrowser.org/): Leve e perfeito para visualizar bancos SQLite.

### 🐧 Linux e Terminal
- [**Windows Terminal**](https://apps.microsoft.com/store/detail/windows-terminal/9N0DX20HK701): Terminal moderno para Windows.
- [**WSL2 (Windows Subsystem for Linux)**](https://learn.microsoft.com/pt-br/windows/wsl/install): Rode Ubuntu diretamente no seu Windows sem máquina virtual.

### 🎨 Design e Diagramação
- [**Draw.io (diagrams.net)**](https://app.diagrams.net/): Gratuito e sem login obrigatório. Perfeito para MER, Fluxogramas e UML.
- [**Excalidraw**](https://excalidraw.com/): Quadro branco virtual com estilo de "desenho à mão". Ótimo para rascunhos rápidos.
- [**GeoGebra Classic**](https://www.geogebra.org/classic): Essencial para visualizar funções, matrizes e geometria.

# 🎓 3. Cursos e Plataformas Gratuitas

Complemente suas aulas com estes conteúdos de altíssima qualidade:

- [**Rocketseat (Discover)**](https://www.rocketseat.com.br/discover): Trilha gratuita de fundamentos da web e lógica.

# 💻 4. Repositórios GitHub Recomendados ("Awesome Lists")

No GitHub, existem listas curadas pela comunidade chamadas "Awesome". Elas reunem os melhores links, bibliotecas e recursos sobre um tema:

- 🐍 [**awesome-python**](https://github.com/vinta/awesome-python): A lista definitiva de frameworks, bibliotecas e recursos Python.
- ☕ [**awesome-java**](https://github.com/akullpp/awesome-java): Frameworks, bibliotecas e softwares incríveis do ecossistema Java.
- 🗄️ [**awesome-sql**](https://github.com/dhamaniasad/awesome-postgres) (Foco em PostgreSQL): Ferramentas e recursos para SQL.
- 🤖 [**awesome-machine-learning**](https://github.com/josephmisiti/awesome-machine-learning): Cursos, livros e bibliotecas de IA/ML.
- 📝 [**cheatsheets**](https://github.com/rstacruz/cheatsheets): Folhas de referência rápida para quase todas as linguagens e ferramentas.

# 📚 5. Documentações Oficiais (A Fonte da Verdade)

Sempre que tiver dúvida, a documentação oficial é mais confiável que qualquer fórum:

- [**Python Docs**](https://docs.python.org/pt-br/3/): Documentação completa em português.
- [**MDN Web Docs (Mozilla)**](https://developer.mozilla.org/pt-BR/): A bíblia do desenvolvimento Web (HTML, CSS, JS).
- [**W3Schools**](https://www.w3schools.com/): Ótimo para referência rápida e testes interativos de SQL, Python, C++, etc.
- [**GeeksforGeeks**](https://www.geeksforgeeks.org/): Excelente para algoritmos, estruturas de dados e dúvidas específicas de C/C++ e Java.

# 🤖 6. Inteligência Artificial e Produtividade

Use a IA para acelerar seu aprendizado, não para substituir seu pensamento:

- [**ChatGPT (OpenAI)**](https://chat.openai.com/): O padrão da indústria para conversação e geração de código.
- [**Claude (Anthropic)**](https://claude.ai/): Excelente para resumir textos longos e analisar código com grande contexto.
- [**Perplexity AI**](https://www.perplexity.ai/): Um "Google com IA". Ótimo para pesquisar documentações e encontrar respostas com fontes reais.
- [**GitHub Copilot**](https://github.com/features/copilot): Assistente de código que sugere linhas inteiras enquanto você digita (gratuito para estudantes com GitHub Student Developer Pack).
- [**Phind**](https://www.phind.com/): Motor de busca e assistente de código focado especificamente em desenvolvedores.
