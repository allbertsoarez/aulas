# [Nodejs](https://nodejs.org/pt)
O Node.js® é um ambiente de execução JavaScript gratuito, de código aberto e multiplataforma, que permite aos desenvolvedores criar servidores, aplicativos web, ferramentas de linha de comando e scripts.

**INSTALAÇÃO**

O Node.js é o motor que vamos usar. Ele vem acompanhado do npm (Node Package Manager), que é a "loja de aplicativos" do Node, onde baixamos as bibliotecas (como o Next.js e o Prisma).

1. Acesse o site oficial: [nodejs.org](https://nodejs.org/pt-br)

2. Você verá dois botões grandes de download. **Clique sempre na versão LTS (Long Term Support)**.
   - Dica do Sênior: A versão "Current" (Atual) tem as novidades mais recentes, mas pode ter bugs. A LTS é a versão estável, testada e recomendada para 99% dos projetos profissionais.

3. Baixe o instalador para o seu sistema (Windows ou Mac) e instale como qualquer programa normal (vá clicando em "Next/Avançar" até o fim).
