# As Melhores Informações para Estudo e Aprimoramento em Python

## 📦 Bibliotecas e Frameworks

### [Manim](https://www.manim.community/)
Biblioteca para animações matemáticas e de dados (excelente para professores!).
- **Repositório:** https://github.com/ManimCommunity/manim

### [Python BCB](https://wilsonfreitas.github.io/python-bcb/)
Interface Python para serviços web do Banco Central do Brasil.
- **Repositório:** https://github.com/wilsonfreitas/python-bcb

### [Validate Doc BR](https://alvarofpp.github.io/validate-docbr/#/)
Pacote Python para validação de documentos brasileiros (CPF, CNPJ, etc.).
- **Repositório:** https://github.com/alvarofpp/validate-docbr

### [yfinance](https://ranaroussi.github.io/yfinance)
Biblioteca para obter dados históricos do mercado financeiro (Yahoo Finance).
- **Repositório:** https://github.com/ranaroussi/yfinance
