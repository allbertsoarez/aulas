# GitDesktop
Cliente Git para desktop, nativo de IA e com foco em teclado, que combina a facilidade do GitHub Desktop com gerenciamento avançado de Git, PRs, issues, discussões, ações e notificações; integra GitLab, Bitbucket, Jira, fluxos de trabalho com agentes, IA multi-provedor, privacidade com foco na linha de comando e atualização automática via Tauri + React.

- https://gitdesktop.app/
- https://github.com/theBGuy/GitDesktop
