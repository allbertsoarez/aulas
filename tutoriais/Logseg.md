# Logseg
 Aplicativo de anotações inteligentes

Logseg é um editor de notas inteligentes open source. Seu objetivo é que você não esqueça nada, pois tudo pode ser armazenado com eficiência. </br>
O aplicativo trabalha de forma cronológica, tudo que é criado é armazenado por data e hora.</br>
