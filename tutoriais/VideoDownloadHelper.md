# Video DownloadHelper

É uma [extensão](https://pt.wikipedia.org/wiki/Add-on_(Mozilla) "Add-on (Mozilla)") para o navegador [Firefox](https://pt.wikipedia.org/wiki/Firefox "Firefox") e [Google Chrome](https://pt.wikipedia.org/wiki/Google_Chrome "Google Chrome"). Permite ao usuário baixar vídeos de sites que transmitem vídeos via [HTTP](https://pt.wikipedia.org/wiki/Hypertext_Transfer_Protocol "Hypertext Transfer Protocol"). A extensão foi desenvolvida por Michel Gutierrez.
