# 🚀 Flexpilot

## 📌 O que é o Flexpilot?
O **Flexpilot** é um ambiente de desenvolvimento integrado (IDE) nativo de IA, de código aberto e com foco absoluto na privacidade. Construído como um *fork* do VS Code, sua filosofia central é a **flexibilidade e a soberania do desenvolvedor**: ao contrário de outras IDEs de IA que prendem o usuário a um modelo específico ou coletam dados, o Flexpilot adota a abordagem "BYOM" (*Bring Your Own Model*). Isso permite que você conecte suas próprias chaves de API de provedores de sua escolha (como OpenAI, Anthropic, Google) ou, para privacidade total, utilize modelos locais e offline (como Ollama ou LM Studio), mantendo o controle absoluto sobre seu código e seus dados.

- **Categoria:** IDE Nativa de IA e Editor de Código
- **Plataforma:** Windows / macOS / Linux / Web (Navegador)
- **Palavras-chave:** Inteligência Artificial, Código Aberto, Privacidade, BYOM (Bring Your Own Model), VS Code Fork, Produtividade, Ollama

---

## ✨ Principais Destaques
- **Soberania de Dados e Privacidade (BYOM):** Você decide qual modelo de linguagem usar. Pode ser um serviço em nuvem de sua confiança ou um modelo rodando 100% localmente na sua máquina, garantindo que seu código nunca saia do seu dispositivo.
- **Ecossistema Familiar do VS Code:** Por ser um *fork* direto, oferece compatibilidade total com o vasto mercado de extensões, temas e atalhos do VS Code, proporcionando uma transição suave e imediata.
- **Ferramentas de IA Integradas e Contextuais:** Inclui preenchimento de código (*code completions*), edição em múltiplos arquivos simultaneamente, chat embutido no editor, chat no terminal e até chat por voz, tudo ciente do contexto do seu projeto.
- **Versão Web Instantânea:** Além do aplicativo desktop, oferece uma versão leve baseada em navegador que permite explorar repositórios do GitHub e codificar com IA diretamente na web, sem instalação.

---

## 🚀 Instalação e Primeiros Passos

O Flexpilot é projetado para ser acessível tanto para quem busca potência no desktop quanto para quem precisa de agilidade na web.

**Opção 1: Aplicativo Desktop (Recomendado para projetos locais e privacidade máxima)**
- Baixe o instalador nativo para **Windows**, **macOS** ou **Linux** diretamente no site oficial.

**Opção 2: Versão Web (Para acesso rápido e exploração de repositórios)**
- Acesse a versão web diretamente pelo navegador para codificar instantaneamente sem configurar nada localmente.

**Primeiros Passos:**
1. Abra o Flexpilot. Na primeira execução, você será guiado para configurar seu provedor de IA.
2. **Para uso local (Máxima Privacidade):** Instale o [Ollama](https://ollama.com/) no seu sistema, baixe um modelo (ex: `ollama run llama3`) e configure o Flexpilot para se conectar à API local do Ollama (geralmente `http://localhost:11434`).
3. **Para uso em Nuvem:** Insira sua chave de API de um provedor compatível (ex: OpenAI, Anthropic, Google Gemini ou GitHub Models).
4. Abra uma pasta de projeto. Use `Ctrl+I` (ou `Cmd+I`) para abrir o *Inline Chat* e pedir para a IA refatorar uma função ou explicar um bloco de código complexo.

### 💡 Nota sobre a Metodologia de Estudo
A arquitetura e a filosofia do **Flexpilot** oferecem analogias excepcionais para a sua metodologia de estudo de temas complexos ou longos, especialmente no ensino da matemática:

1. **BYOM (Bring Your Own Model) e a Autonomia Estratégica:** Assim como o Flexpilot permite que o usuário escolha o modelo de IA que melhor se adapta ao seu custo, necessidade de privacidade e precisão, o aluno deve desenvolver a autonomia para escolher a "ferramenta mental" adequada para cada problema. Nem todo problema exige uma "superfórmula" complexa; às vezes, um modelo mental mais simples e direto (como uma estimativa ou um desenho geométrico) é a escolha mais eficiente e elegante.
2. **Processamento Local vs. Nuvem (Internalização do Conhecimento):** A capacidade de rodar modelos de IA localmente, sem enviar dados para fora, é uma analogia perfeita para o conhecimento internalizado. Quando o aluno domina os fundamentos (tabuada, produtos notáveis, teoremas básicos), ele possui um "modelo local" rápido e confiável no cérebro. Isso o libera da necessidade de "consultar a API" (o livro, a fórmula colada ou o professor) para cada passo trivial, liberando capacidade cognitiva para focar na lógica de alto nível da resolução.
3. **Chat no Terminal e Inline Chat (Diálogo com o Próprio Raciocínio):** As ferramentas de chat embutidas do Flexpilot permitem questionar o código exatamente onde a dúvida surge. No estudo, incentive o aluno a praticar o "diálogo interno" ou o *rubber duck debugging* (explicar o problema para um pato de borracha). Ao escrever nas margens do caderno "Por que eu usei essa propriedade aqui?" ou "O que este passo está tentando alcançar?", o aluno transforma a resolução passiva em uma revisão ativa e crítica, identificando falhas de lógica no momento exato em que ocorrem.
