# 📂 OSINT, SEGURANÇA E PRIVACIDADE

## 🔒 Privacidade e Proteção de Rede
- **[Rethink App (celzero)](https://github.com/celzero/rethink-app)**: *Cliente de DNS over HTTPS/Tor/DNSCrypt, proxificador WireGuard, firewall e rastreador de conexão para Android.*
- **[pico-fido (polhenarejos)](https://github.com/polhenarejos/pico-fido)**: *Implementação de chave de segurança FIDO (Passkey) para Raspberry Pi Pico e ESP32, permitindo autenticação de hardware personalizada.*

## 🔍 Inteligência de Fontes Abertas (OSINT)
- **[GTFOBins](https://github.com/GTFOBins/GTFOBins.github.io)** 🚨 **[PRIORIDADE ALTA]**: *O catálogo definitivo e curado de binários Unix para bypass de restrições de segurança e escalonamento de privilégios.*
- **[OpenOSINT (OpenOSINT)](https://github.com/OpenOSINT/OpenOSINT)**: *Motor de código aberto para verificações passivas de OSINT, reunindo múltiplas ferramentas de investigação (DNS, WHOIS, breaches, etc.) em uma interface unificada.*
- **[God-s-eye (LeonardoCides)](https://github.com/LeonardoCides/God-s-eye)**: *Motor de vigilância OSINT de alta velocidade projetado para rastrear pegadas digitais em múltiplas plataformas sociais usando enumeração multithread.*
- **[Eyes-of-God (Kalyel473)](https://github.com/Kalyel473/Eyes-of-God)**: *Ferramenta robusta de monitoramento, análise, segurança e inteligência de fontes abertas (OSINT).*
- **[OSINTCorrelator (Kalyel473)](https://github.com/Kalyel473/OSINTCorrelator)**: *Utilitário para correlação de dados e cruzamento de informações em investigações de inteligência de fontes abertas.*
- **[Olho-de-Deus (EduardoFelype)](https://github.com/EduardoFelype/Olho-de-Deus)**: *Ferramenta de pentest automatizado em Python para análise de segurança, identificação de vazamentos (JWT, API keys) e geração de relatórios.*

## ⚔️ Reconhecimento e Segurança Ofensiva
- **[CeWL (digininja)](https://github.com/digininja/CeWL)**: *Gerador de listas de palavras personalizadas (Custom Word List Generator) que cria dicionários a partir de palavras encontradas em um site alvo.*
- **[Storm-Breaker (ultrasecurity)](https://github.com/ultrasecurity/Storm-Breaker)**: *Framework de engenharia social com clonagem de páginas, proxy MITM, captura de credenciais, extração de sessão e monitoramento em tempo real.*
- **[JarvvisSecurity (Kalyel473)](https://github.com/Kalyel473/JarvvisSecurity)**: *Conjunto de scripts e automação voltado para reconhecimento e testes de segurança.*
