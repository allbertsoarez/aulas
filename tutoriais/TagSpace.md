# TagSpace
TagSpaces é um gerenciador de documentos offline, de código aberto, com suporte para marcação. <br>

**TagSpaces** é um aplicativo gratuito, sem dependência de fornecedor, de código aberto para organizar, anotar e gerenciar arquivos locais com a ajuda de tags. Ele apresenta funcionalidades avançadas de anotações e alguns recursos de aplicativos de tarefas. O aplicativo está disponível para Windows, Linux, Mac OS e Android. Fornecemos uma extensão web clipper para Firefox, Edge e Chrome para fácil coleta de conteúdo online na forma de arquivos locais.
