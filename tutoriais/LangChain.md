# LangChain
**LangChain** é um framework de código aberto para o desenvolvimento de aplicações usando modelos de linguagem grandes. Tratando-se de um _framework_ para integração com modelos de linguagem, os casos de uso da LangChain intersectam-se com aqueles dos modelos em si, e incluem sumarização de texto, chat bots, e análise de código.
