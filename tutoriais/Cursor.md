# ⚡ Cursor AI

## 📌 O que é o Cursor AI?
O **Cursor** é um editor de código "AI-first" (construído com a IA no centro da experiência), projetado como uma evolução natural do VS Code. Sua principal filosofia é atuar como um verdadeiro parceiro de programação (pair programmer), oferecendo um "controle de autonomia" ajustável: desde sugestões pontuais de código até agentes autônomos capazes de planejar, escrever, testar e corrigir funcionalidades inteiras em múltiplos arquivos. Ele indexa e compreende todo o contexto do seu projeto, garantindo que as respostas da IA sejam precisas, relevantes e integradas à sua base de código real.

- **Categoria:** Editor de Código e Agente de IA para Desenvolvimento
- **Plataforma:** Windows / macOS / Linux
- **Palavras-chave:** Inteligência Artificial, Programação, Produtividade, Codebase Awareness, Multiagente, Automação

---

## ✨ Principais Destaques
- **Consciência Total da Base de Código (Codebase Awareness):** O Cursor indexa semanticamente todo o seu projeto. Ao fazer uma pergunta ou solicitar uma alteração, a IA não "alucina" genericamente; ela lê os arquivos relevantes, entende a arquitetura e propõe soluções que respeitam o contexto existente.
- **Controle de Autonomia Ajustável:** O usuário decide o nível de intervenção da IA. Pode ser uma edição pontual e rápida (ataalho `Cmd/Ctrl + K`), um chat de esclarecimento (`Cmd/Ctrl + L`) ou um agente autônomo que planeja e executa tarefas complexas em segundo plano (Modo "Agent" ou "Composer").
- **Suporte a Múltiplos Modelos de Ponta:** Permite alternar facilmente entre os melhores modelos do mercado (como Claude 3.5/4 Sonnet, GPT-4o/5, Gemini e modelos locais), escolhendo o mais adequado para cada tarefa (ex: raciocínio complexo vs. velocidade de geração).
- **Integração Profunda no Fluxo de Trabalho:** Funciona nativamente no terminal, revisa Pull Requests, integra-se ao Slack, GitHub e GitLab, e permite a criação de "Regras" (Rules) personalizadas para que a IA siga sempre os padrões de estilo e arquitetura da sua equipe ou projeto.

## 🚀 Instalação e Primeiros Passos

O Cursor é projetado para ser uma transição suave para quem já utiliza o VS Code, importando automaticamente suas extensões, temas e configurações.

**Opção 1: Instalação no Desktop (Recomendado)**
- Baixe o instalador nativo para **Windows**, **macOS** ou **Linux** diretamente do site oficial. Durante a instalação, opte por importar suas configurações do VS Code para uma experiência familiar imediata.

**Primeiros Passos:**
1. Abra o Cursor e abra a pasta do seu projeto. O software começará a indexar o código em segundo plano (você verá um indicador de "Indexing").
2. Pressione `Ctrl + L` (ou `Cmd + L` no Mac) para abrir o Chat. Faça uma pergunta sobre o código, como: "Explique como a função de autenticação neste arquivo funciona".
3. Pressione `Ctrl + K` (ou `Cmd + K`) dentro de um arquivo para pedir uma edição direta. Ex: "Adicione um tratamento de erro try-catch nesta função".
4. *Dica de fluxo:* Use o recurso `@` no chat para mencionar arquivos específicos, pastas ou até mesmo a documentação oficial (ex: `@docs`) para que a IA baseie sua resposta exatamente no material que você fornecer.

### 💡 Nota sobre a Metodologia de Estudo
A arquitetura e a filosofia do **Cursor AI** oferecem analogias excepcionais para a sua metodologia de estudo de temas complexos ou longos, especialmente no ensino da matemática:

1. **O "Controle de Autonomia" (Scaffolding e Andaimagem Cognitiva):** O Cursor permite escolher entre uma dica pontual (`Cmd+K`) ou um agente que resolve tudo. No ensino da matemática, isso reflete o conceito de *scaffolding* (andaimagem). O professor (ou o próprio aluno, ao estudar) deve calibrar o nível de ajuda: às vezes, uma pequena dica é suficiente para desbloquear o raciocínio; outras vezes, é necessário decompor o problema inteiro passo a passo. O objetivo final, no entanto, é sempre aumentar a autonomia do aluno até que ele possa "codificar" a solução sozinho.
2. **Indexação da Base de Código (Conexão de Conceitos e Contexto):** O Cursor é poderoso porque "lê" e conecta todo o projeto antes de responder. Na matemática, um conceito nunca está isolado. Incentive o aluno a construir uma "base de conhecimento" interligada (no caderno ou no Obsidian), onde teoremas, fórmulas e exercícios resolvidos estejam contextualizados. Resolver um problema de Cálculo, por exemplo, exige que o "agente mental" acesse e conecte conhecimentos prévios de Álgebra e Geometria de forma fluida.
3. **Modo "Plan" e Revisão (Metacognição e Planejamento):** Antes de escrever o código, o Cursor pode gerar um plano de ação e pedir aprovação do usuário. Na resolução de problemas matemáticos complexos, treine o aluno a usar o "Modo Plan" mental: antes de calcular, ele deve verbalizar ou anotar o plano ("O que sei? O que quero? Qual teorema se aplica aqui?"). Após a execução, a "revisão do agente" equivale à verificação da resposta, garantindo que cada passo do plano foi logicamente válido, transformando o erro em um ponto de ajuste, não de frustração.
