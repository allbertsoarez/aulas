# Bitchat

Aplicativo de mensagens peer-to-peer seguro, descentralizado e que funciona em redes mesh Bluetooth.</br>
Não requer internet para chats mesh, nem servidores, nem números de telefone — apenas comunicação criptografada.</br>
O Bitchat também suporta canais geohash, que usam uma conexão de internet para conectar você a outras pessoas na sua área geográfica.</br>

Bitchat é um aplicativo de mensagens criptografadas que funciona sem internet, utilizando uma rede mesh Bluetooth LE para conectar dispositivos próximos==. Desenvolvido por [Jack Dorsey](https://www.google.com/search?sca_esv=a67f889c4de23fbe&sxsrf=AE3TifMSAKXLl018RAxNAZMtnHWFmjg-iw%3A1760409769934&q=Jack+Dorsey&sa=X&ved=2ahUKEwi23Pu31aKQAxWHjpUCHYQ_G9QQxccNegQIIhAB&mstk=AUtExfAivyA-B6qtKhVZcWTiqXFTY9EL28SBAXWqYzfkpF6xXWR-idS0yRMIgr6MAiNjG1Zs5Ff37X1zx6Z2gyrIjDZDkPyPDwlBEwxWqiGf82nLjH4uodsnfX5a9ieOEyqXXMOy-KkpEot13aA2yVdypMuQjHgxinwVz4k2yF3oHLx1luNKjH12FWsa_r-506BqJ2HASqPVmBXuJGVtKC9wJww0xUFw3ZzWOVhPgvg69urkY-p5j6S88fS6TTXto0VroAVRuHIP42BZQ9SzWRQ6l0mP&csui=3), o app permite a comunicação mesmo em locais sem sinal ou em situações de falha na rede. A rede mesh funciona como uma cadeia, onde cada dispositivo encaminha mensagens para os próximos, ampliando o alcance para até 300 metros.
