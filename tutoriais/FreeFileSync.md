# [FreeFileSync](https://freefilesync.org/)
O FreeFileSync é um software de comparação e sincronização de pastas que cria e gerencia cópias de segurança de todos os seus arquivos importantes. Em vez de copiar cada arquivo a cada vez, o FreeFileSync identifica as diferenças entre uma pasta de origem e uma de destino e transfere apenas a quantidade mínima de dados necessária. O FreeFileSync é um software de código aberto, disponível para Windows, macOS e Linux.
