# Bolt.diy
Bem-vindo ao bolt.diy, a versão oficial de código aberto do Bolt.new, que permite escolher o LLM que você usa para cada prompt! Atualmente, você pode usar OpenAI, Anthropic, Ollama, OpenRouter, Gemini, LMStudio, Mistral, xAI, HuggingFace, DeepSeek, Groq, Cohere, Together, Perplexity, Moonshot (Kimi), Hyperbolic, GitHub Models, Amazon Bedrock e provedores semelhantes ao OpenAI — e ele pode ser facilmente estendido para usar qualquer outro modelo suportado pelo Vercel AI SDK! 
Veja as instruções abaixo para executar isso localmente e estendê-lo para incluir mais modelos.


- https://github.com/stackblitz-labs/bolt.diy
- https://stackblitz-labs.github.io/bolt.diy/
