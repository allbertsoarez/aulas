# [Libredb](https://libredb.org/)
Uma única aba do navegador para PostgreSQL, MySQL, Oracle, SQL Server, MongoDB, Redis, SQLite, Couchbase, ClickHouse, Druid, DuckDB, Turso e muito mais. Um IDE SQL de código aberto com SSO, trilha de auditoria e consultas assistidas por IA, licenciado sob a licença MIT, sem restrições para uso corporativo.
