# 📝 Arquivos Portugol - Algoritmos

Esta pasta é destinada exclusivamente ao armazenamento dos arquivos de código em Portugol (pseudocódigos) relacionados ao módulo de Algoritmos. O objetivo é manter os arquivos práticos organizados e separados do material teórico.

Os arquivos abaixo podem ser abertos diretamente em editores de texto ou importados para IDEs como o **VisuAlg** ou **Portugol Studio**.

## 📂 Índice de Arquivos

| Arquivo | Descrição | Tópico Relacionado |
| :--- | :--- | :--- |
| [`ola_mundo.por`](./ola_mundo.por) | Meu primeiro algoritmo: exibindo mensagens na tela. | 1. Introdução |
| [`variaveis_tipos.por`](./variaveis_tipos.por) | Exemplos de declaração de variáveis, entrada e saída (Soma de dois números). | 4. Entrada, Processamento e Saída |
| [`condicionais_se.por`](./condicionais_se.por) | Exemplos práticos de uso do `SE` / `SENAO` (Verifica maioridade). | 5. Estruturas Condicionais |
| [`repeticao_para.por`](./repeticao_para.por) | Exemplos de laços de repetição com `PARA` (Cálculo de Tabuada). | 6. Estruturas de Repetição |
| [`vetores_matrizes.por`](./vetores_matrizes.por) | Manipulação de arrays (vetores de notas) e matrizes (tabela 3x3). | 7. Estruturas Homogêneas |

> **Nota:** Adicione novos arquivos nesta tabela conforme for criando os algoritmos. Basta seguir o padrão `[Nome do Arquivo](./nome_do_arquivo.por)`.
