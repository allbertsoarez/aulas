# 📝 Arquivos Portugol - Algoritmos

Esta pasta é destinada exclusivamente ao armazenamento dos arquivos de código em Portugol (pseudocódigos) relacionados ao módulo de Algoritmos. O objetivo é manter os arquivos práticos organizados e separados do material teórico.

## 📂 Índice de Arquivos

| Arquivo | Descrição | Tópico Relacionado |
| :--- | :--- | :--- |
| `ola_mundo.por` | Meu primeiro algoritmo: exibindo mensagens na tela. | Introdução |
| `variaveis_tipos.por` | Exemplos de declaração e uso de variáveis. | Variáveis e Tipos de Dados |
| `condicionais_se.por` | Exemplos práticos de uso do SE / SENÃO. | Estruturas Condicionais |
| `repeticao_para.por` | Exemplos de laços de repetição com PARA e ENQUANTO. | Estruturas de Repetição |
| `vetores_matrizes.por` | Manipulação de arrays e matrizes. | Estruturas Homogêneas |

> **Nota:** Adicione novos arquivos nesta tabela conforme for criando os algoritmos. Os arquivos podem ser abertos diretamente em editores de texto ou importados para o VisuAlg/Portugol Studio.
