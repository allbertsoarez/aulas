# 📐 Arquivos GeoGebra - Matemática

Esta pasta armazena os arquivos dinâmicos (`.ggb`) e imagens geradas no GeoGebra, utilizados como material de apoio visual para a apostila de Matemática.

Os applets abaixo podem ser abertos diretamente no **GeoGebra Classic** ou no navegador através do site [geogebra.org](https://www.geogebra.org/).

## 📂 Índice de Arquivos

| Arquivo | Descrição | Tópico Relacionado |
| :--- | :--- | :--- |
| [`funcao_1grau.ggb`](./funcao_1grau.ggb) | Gráfico interativo de função afim (f(x) = ax + b) com controles deslizantes para `a` e `b`. | 1. Funções |
| [`funcao_2grau.ggb`](./funcao_2grau.ggb) | Parábola com controles para `a`, `b` e `c`, mostrando raízes e vértice dinamicamente. | 1. Funções |
| [`circulo_trigonometrico.ggb`](./circulo_trigonometrico.ggb) | Simulação do círculo trigonométrico com seno, cosseno e tangente projetados nos eixos. | 2. Trigonometria |
| [`matrizes_operacoes.ggb`](./matrizes_operacoes.ggb) | Representação visual de multiplicação de matrizes 2x2 com animação passo a passo. | 3. Matrizes |
| [`sistemas_lineares.ggb`](./sistemas_lineares.ggb) | Interpretação geométrica de sistemas 2x2 (retas paralelas, concorrentes e coincidentes). | 3. Matrizes / Sistemas |

> **📝 Nota de Criação:** 
> Os arquivos `.ggb` devem ser criados no GeoGebra Classic e exportados como `.ggb`. 
> Para abrir, basta clicar no arquivo no GitHub e baixar, ou abrir diretamente no app/site do GeoGebra.

> **💡 Dica:** Você pode incorporar esses applets em apresentações ou documentos PDF exportando-os como **imagem GIF animada** ou **HTML5 interativo** diretamente pelo GeoGebra (Arquivo > Exportar).
