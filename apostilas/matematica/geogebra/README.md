# 📐 Arquivos GeoGebra - Matemática

Esta pasta armazena os arquivos dinâmicos (`.ggb`) e imagens geradas no GeoGebra, utilizados como material de apoio visual para a apostila de Matemática.

## 📂 Índice de Arquivos

| Arquivo | Descrição | Tópico Relacionado |
| :--- | :--- | :--- |
| `funcao_1grau.ggb` | Gráfico interativo de função afim. | Funções |
| `circulo_trigonometrico.ggb` | Simulação do círculo trigonométrico. | Trigonometria |
| `matrizes_operacoes.ggb` | Representação visual de multiplicação de matrizes. | Matrizes |

> **Dica:** Você pode baixar os arquivos clicando neles na lista acima ou clonando o repositório.
