# INTRODUÇÃO E PREPARAÇÃO DO AMBIENTE

## 1. CONTEXTO E MOTIVAÇÃO
- 1.1 - Por que aprender C? (A base de linguagens como C++, Java, Python e Rust)
- 1.2 - Aplicações reais no mercado atual (Sistemas operacionais, embarcados, alta performance)
- 1.3 - O objetivo deste curso: desenvolver um modelo mental sólido sobre a memória

## 2. PREPARAÇÃO DO AMBIENTE DE DESENVOLVIMENTO
- 2.1 - Instalação do compilador GCC (Windows via MinGW, Linux via apt, macOS via Homebrew)
- 2.2 - Configuração do Visual Studio Code e instalação das extensões essenciais
- 2.3 - O ciclo de compilação: do código fonte ao executável (Pré-processamento, Compilação, Montagem e Linkagem)

## 3. O PRIMEIRO CONTATO COM O CÓDIGO
- 3.1 - Escrevendo e executando o "Hello World"
- 3.2 - A diretiva de pré-processamento [`#include`](https://en.cppreference.com/w/c/preprocessor/include)
- 3.3 - A função principal [`main`](https://en.cppreference.com/w/c/language/main_function)
- 3.4 - A função de saída formatada [`printf`](https://en.cppreference.com/w/c/io/printf) e o caractere de nova linha `\n`
- 3.5 - Compilando manualmente via terminal (`gcc main.c -o main` e `./main`)
