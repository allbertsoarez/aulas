# 🚀 DESAFIO PRÁTICO DO MÓDULO 2

## 🎯 Objetivo
Criar uma "Calculadora de Área de Círculo" interativa, praticando variáveis, entrada/saída formatada e constantes.

## 📋 Requisitos
1. Defina o valor de PI como uma constante (use `const float` ou `#define`).
2. Peça ao usuário para digitar o valor do raio (use `float` ou `double`).
3. Calcule a área usando a fórmula: $Area = PI \times raio^2$.
4. Exiba o resultado formatado com exatamente **4 casas decimais**.
